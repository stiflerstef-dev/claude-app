# claude-remote

Manage Claude Code sessions from your phone — start, monitor, send messages, and approve actions from anywhere.

## Architecture

```
┌─────────────────────────────────────────────────────────┐
│  Developer Machine                                        │
│                                                           │
│  ┌──────────────────────────────────────────────────┐   │
│  │  daemon/  (Python)                                │   │
│  │  • Scans ~/projects for CLAUDE.md                 │   │
│  │  • Spawns claude --dangerously-skip-permissions   │   │
│  │    via pty for each session                       │   │
│  │  • Streams output / forwards commands             │   │
│  └────────────────────┬─────────────────────────────┘   │
└───────────────────────│─────────────────────────────────┘
                        │ WebSocket /daemon
                        ▼
┌───────────────────────────────────────────────────────────┐
│  VPS (behind Cloudflare Tunnel)                           │
│                                                           │
│  ┌────────────────────────────────────────────────────┐  │
│  │  relay/  (Node.js + Fastify)  :3030                 │  │
│  │  • /daemon  WebSocket — daemon connects here        │  │
│  │  • /app     WebSocket — mobile app connects here    │  │
│  │  • POST /auth/token — issues JWT for app            │  │
│  │  • GET  /health                                     │  │
│  │  • Broker routes messages between both sides        │  │
│  │  • Audit log → logs/audit.jsonl                     │  │
│  └────────────────────┬────────────────────────────────┘  │
└───────────────────────│────────────────────────────────────┘
                        │ WebSocket /app
                        ▼
┌─────────────────────────────────────┐
│  Mobile  (React Native + Expo)      │
│                                     │
│  • Dashboard: all sessions          │
│  • Session view: chat bubbles       │
│  • Approval bar: approve/deny       │
│  • Voice input (STT/TTS)            │
└─────────────────────────────────────┘
```

---

## Setup: Relay

```bash
cd relay
cp .env.example .env
# Edit .env — set DAEMON_TOKEN and APP_SECRET

npm install
npm run dev
```

The relay listens on port `3030`. In production, put it behind Cloudflare Tunnel (see `infra/`).

---

## Setup: Daemon

```bash
cd daemon
pip install -r requirements.txt

# First run creates ~/.claude-remote/config.json
python main.py

# Edit ~/.claude-remote/config.json:
# {
#   "projects_dir": "~/projects",
#   "relay_url": "wss://relay.yourdomain.com",
#   "auth_token": "<value of DAEMON_TOKEN from relay .env>",
#   "device_id": "<auto-generated>"
# }

python main.py
```

The daemon expects `claude` CLI to be installed and on `$PATH`.

## Setup: App

```bash
cd app
npm install

# Install Expo Go on your phone, or build a dev client:
npx expo start
```

## First-Time Flow

1. Start the relay on your VPS: `npm run dev`
2. Start the daemon on your machine: `python main.py`
3. Open the app on your phone
4. On the login screen, paste:
   - **Relay URL**: `wss://relay.yourdomain.com`
   - **App Token**: get one by calling `POST /auth/token` on the relay
5. Tap **Connect** — you'll see your projects appear

---

## Token Acquisition

```bash
# Get an app JWT (stub auth — accepts any request in dev):
curl -X POST https://relay.yourdomain.com/auth/token
# Returns: {"token":"eyJ..."}
```

Paste this token in the app login screen.

## Cloudflare Tunnel

```bash
# Install cloudflared, then:
cloudflared tunnel login
cloudflared tunnel create claude-remote
cloudflared tunnel route dns claude-remote relay.yourdomain.com

# Run tunnel (relay must be running on :3030):
cloudflared tunnel --config infra/cloudflare-tunnel.yml run
```

---

## Project Detection

The daemon treats any subdirectory containing a `CLAUDE.md` file as a valid project.
It re-scans every 30 seconds, so new projects appear automatically.
